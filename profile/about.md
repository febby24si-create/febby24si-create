# About

<img src="../assets/divider.svg" width="100%" />

</div>

<br/>

I build software that is fast, deliberate, and quiet in its complexity.

My focus sits at the intersection of **frontend craftsmanship** and **backend architecture** — interfaces that feel inevitable, systems that don't break under pressure.

Currently a Sistem Informasi student, spending most hours shipping full-stack products end to end: schema design, API architecture, state management, and the last-mile UI details most people skip.

<br/>

### What I care about

```
→ Scalable application architecture
→ Interfaces engineered, not decorated
→ Backend systems that are boring in the best way
→ Applied artificial intelligence
→ Shipping over talking
```

<br/>

### How I work

I start every project with the data model, not the UI. If the schema is wrong, no amount of polish fixes it later. Once the architecture is settled, I move to interface — and that's where the obsession kicks in: spacing, motion, timing, contrast. Small things compound into something that feels expensive.

Not interested in trends. Interested in things that still work in five years.
