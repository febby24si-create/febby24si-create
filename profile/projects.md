## EstherGarage
**Garage Management System**

A full-stack platform for automotive service businesses — booking, customer relationship management, and loyalty, unified into one operational dashboard.

- Role-based access: Guest, Member, Admin
- Real-time booking engine with status lifecycle
- Loyalty program with tiered membership
- Analytics dashboard with live KPIs
- Inventory and service tracking

**Stack:** React · Supabase · Tailwind CSS

<br/>

## TikoemPoint
**Coffee Shop POS**

A point-of-sale system built for small F&B operations that need speed at the counter and clarity in the back office.

- Point-of-sale checkout flow
- Inventory tracking with low-stock alerts
- Sales and revenue reporting
- Employee shift and role management
- Daily/weekly performance dashboard

**Stack:** React · PostgreSQL

<br/>

## SIPEDES
**Village Information System**

A digital administration system for village-level government, replacing paper-based processes with structured digital records.

- Population data management
- Digital letter/document request services
- Administrative dashboard
- Report generation for local government

**Stack:** Laravel · MySQL
